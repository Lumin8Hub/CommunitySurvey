# Community Impact Report 2025-26

Responsive infographic microsite for sharing the findings of the 2025-26 Community Impact Study with the community.

## Local development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```

## Project structure

- `src/components/CISInfographicSite.jsx` — main one-page infographic website.
- `src/styles.css` — responsive visual system and layout.
- `wireframes/cis-infographic-wireframes.md` — desktop/mobile wireframes and data modules used to build the site.
